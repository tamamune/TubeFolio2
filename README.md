# TubeFolio2

Vivaldi(Chromium系)用 YouTube 拡張機能。TubeFolio とは独立した新規実装です。

## インストール
1. `vivaldi://extensions` を開く → 右上「デベロッパーモード」ON
2. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダ(`C:\Claude\TubeFolio2`)を選択

## 機能
- **左パネル**: YouTube左端の★タブで開閉。グループ作成/名前変更/削除、グループ別のお気に入り一覧、検索。視聴中の動画はチップをクリックでグループに追加/解除。
- **一覧のバッジ**: サムネイル左上に ☆(未登録) / ★(登録済・グループ色)。登録済みは枠線も付く。クリックで即登録/解除、`▾` でグループ選択。
- **視聴履歴**: 5秒以上再生した動画を記録(広告・一時停止中は除外)。拡張アイコンのクリックで「履歴・分析」ページが開く。
- **分析**: 総視聴時間、日別/時間帯別/曜日別、チャンネル・動画ランキング、お気に入り視聴率、グループ内訳。
- **表示/非表示**: 設定ページで 左パネル / バッジ / 履歴 / 分析 を個別にON/OFF。

## Google Drive 同期の設定
1. Google Cloud Console でプロジェクト作成 → 「Google Drive API」を有効化
2. OAuth 同意画面を設定(スコープ `drive.appdata`、テストユーザーに自分を追加)
3. 認証情報 → OAuth クライアントID(種類: **ウェブ アプリケーション**)を作成し、承認済みリダイレクトURIに設定ページ表示の URI(`https://<拡張ID>.chromiumapp.org/`)を登録
4. 設定ページにクライアントIDを入力 →「Googleに接続して同期」

同期対象: グループ・お気に入り・機能のON/OFF(Driveの appDataFolder に `tubefolio2-settings.json`)。視聴履歴は端末ローカルのみ(設定ページで書き出し可)。
※拡張IDはフォルダの場所で変わるため、読み込み後にIDが決まってからリダイレクトURIを登録してください。
