# TubeFolio2

PocketTube 風の YouTube 登録チャンネル整理拡張(Vivaldi / Chromium, MV3)。

## インストール
`vivaldi://extensions` → デベロッパーモード ON → 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択。

## 使い方
1. 拡張アイコンをクリック → 管理画面。「YouTubeから取り込む」で登録チャンネルを自動取得。
2. 管理画面: グループ作成(アイコン/色)、カード選択やドラッグでグループへ追加(1チャンネルを複数グループに所属可)、検索、並び替え、バックアップ/復元。
3. YouTube の動画カードにマウスを乗せると出る「＋」、またはチャンネル/視聴ページ右下のボタンからグループ追加。
4. 登録チャンネル(/feed/subscriptions)上部のバーでグループ絞り込み・未分類表示・視聴済み(80%以上)を隠す・表示中動画の一括再生(最大50件)。
