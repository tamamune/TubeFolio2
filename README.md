# TubeFolio2

YouTube の登録チャンネルを**フォルダで整理**し、YouTube の画面をもっと使いやすくする Chrome / Vivaldi 向け拡張機能(Manifest V3)です。PocketTube のようなチャンネル整理を土台に、再生ツール・視聴履歴の分析・Google Drive 同期などを備えています。パソコンと Vivaldi for Android の両方で使えます。

- 現在のバージョン: v0.2.0(変更の詳細は [CHANGELOG.md](CHANGELOG.md))
- 設定・登録データはすべて Google Drive(appDataFolder)で、複数の端末と共有できます

## 主な機能

### チャンネルの整理
- **入れ子のフォルダ**で登録チャンネルを管理(アイコン・色つき)。1つのチャンネルを**複数のフォルダ**に入れられます。
- 「YouTubeから取り込む」で登録チャンネルを自動取得。登録を外したチャンネルでもフォルダに入っていれば残り、「🚫 未登録」と表示されます。
- **振り分け補助**: キーワードからフォルダの候補を出します。
- 検索・並び替え・カード選択やドラッグでの追加・バックアップ/復元(JSON)。
- 動画カードの「＋」、チャンネル/視聴ページ右下のボタンからも、フォルダに追加できます。

### 登録フィード・一覧
- 登録チャンネル(/feed/subscriptions)の上部バーで、フォルダ絞り込み・未分類表示・**視聴済み(80%以上)を隠す**・表示中の動画の一括再生(最大50件)。
- フォルダごとの**新着動画・ライブ・ショート**を表示。新着件数は裏で取得するので、開いてすぐ分かります。
- サムネの「🕒 **後で見る**」ボタン。再生リスト「TubeFolio2 後で見る」の管理と、続きから見る。
- サムネのプレビュー再生(埋め込みプレイヤーの先読みで速く表示)。プレビューを視聴履歴に入れない設定もあります。

### 再生画面のツール
- 戻る・進む、**A-B リピート**、字幕の読み上げ、**ブックマーク**(キー操作にも対応)、SponsorBlock、チャプター、コメントの拡張。
- 「H.264 で再生」のオン/オフ、外部プレイヤーとの連携。
- **ショート用のツールパネル**: 5秒シーク、コマ送り、画面クリア、自動で次へ、後で見る、タイマー。スマホ(タッチ)では右端の細い縦パネル、パソコンでは動画の横に表示されます。

### 視聴履歴・分析
- 履歴の閲覧と管理、「分析」を1ページに統合。
- 時間帯の傾向(曜日 × 時間のヒートマップ。就寝時間・作業時間つき)、曜日 × フォルダの積み上げ棒グラフ、チャンネル別などの横棒グラフ。
- 再生時にカテゴリ・公開日・タグ・デバイス・流入経路も記録します。

### 検索・発見
- 検索ページ・急上昇・ランダムタグ、おすすめ動画。

### 通知・集中モード
- フォルダごとの新着通知。
- 曜日・時間帯で動画を見えなくする**集中モード**、就寝時間のお知らせ。

### Google Drive 同期
- 設定・フォルダ・視聴履歴などを、複数のPC・スマホで共有します。
- キーごとの更新時刻で新しい方を採り、2回目からは項目ごと(フォルダ・チャンネル・設定)に**3者統合**するので、別の端末の変更で古い内容に戻りません。
- 起動時・5分ごと・手動で取り込み。初回は Drive を優先します。

### 画面
- **ダーク / ライト両対応**(YouTube のテーマに追従)。
- 下のガラス調バー、スマホの設定のような一覧形式の設定画面。

## インストール

### リリースの zip から
1. [Releases](https://github.com/tamamune/TubeFolio2/releases) から `TubeFolio2-vX.Y.Z.zip` をダウンロードして、好きなフォルダに展開します。
2. `chrome://extensions`(Vivaldi は `vivaldi://extensions`)で「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダを選びます。
4. 更新するときは、新しい zip を同じフォルダに上書き展開して「再読み込み」を押します。拡張機能のIDは固定(`ffjjmiikoghongpjbdcchhgclecokekm`)なので、設定は引き継がれます。

### ソースから
このリポジトリを clone して、フォルダを上と同じ方法で読み込みます。

## 使い方
1. 拡張アイコンをクリックして管理画面を開き、「YouTubeから取り込む」で登録チャンネルを取得します。
2. フォルダを作って、チャンネルを振り分けます(カード選択・ドラッグ・振り分け補助)。
3. YouTube の動画カードの「＋」や「🕒 後で見る」、再生画面のツールを使います。
4. 複数の端末で使うときは、設定で Google Drive にログインして同期をオンにします。

## 開発メモ
- 保存データは `store.js` の `TF.SYNC_KEYS` で同期対象を決めます。新しい storage キーを足したら必ず加えてください。
- 見た目の設定を localStorage に足したら `ui-sync.js` の `OK` に加えます。
- 新しい画面はダーク / ライトの両方で読めるように、色は CSS変数で持ちます。
- `manifest.json` の `key` は消さないでください(拡張機能IDとOAuthのリダイレクトURIが固定されます)。
- 詳しいルールは [CLAUDE.md](CLAUDE.md) を参照してください。

## 構成
| 場所 | 内容 |
| --- | --- |
| `background.js` | サービスワーカー(通知・ルール・同期の呼び出し) |
| `content.js` ほか | YouTube に差し込む画面・機能 |
| `manager.*` | 登録チャンネル管理画面 |
| `page.*` / `histpage.js` / `trdpage.js` | 視聴・履歴・急上昇などのページ |
| `store.js` / `sync.js` | 保存と Google Drive 同期 |
| `shorts-tools.js` | ショート用ツールパネル |
