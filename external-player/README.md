# 外部プレイヤー(mpv / VLC)で開く

再生画面の ⚡ ツール →「▶ 外部プレイヤー」→「で開く」で、今の動画(再生位置つき)をPCのプレイヤーで開きます。
ブラウザの拡張機能はアプリを直接起動できないため、Windows に「受け口」を1回だけ登録します。

- mpv: `mpv.reg` の mpv.exe の場所を直してダブルクリック(yt-dlp も必要)。`ytdl://URL` を mpv が直接受け取ります。
- VLC: `vlc.reg` をダブルクリック(vlc.exe の場所が違えば直す)。
- 初回はブラウザが「このアプリを開きますか」と聞くので、許可してください。
